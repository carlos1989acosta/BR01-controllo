# Dashboard BR01

Il progetto legge automaticamente **report.docx** dalla stessa cartella di `index.html`.

## Utilizzo

Avvia il progetto tramite un server web. Se modifichi `report.docx`, salva il documento e premi **Aggiorna dati**.

La dashboard mostra i dati per mese, i totali giornalieri, i prelievi per fascia oraria dalle 06:00 alle 22:00, le medie dei turni mattina/pomeriggio e i commenti.

Colori delle barre:
- Verde: più di 288 prelievi.
- Giallo: da 228 a 288 prelievi, inclusi.
- Rosso: meno di 228 prelievi.
